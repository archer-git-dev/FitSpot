Сделана панель тренера: регистрация и вход, подтверждение email, восстановление доступа, профиль с фото, недельный график, каталог услуг и правила записи. Telegram реализован, реальный вход ещё требует настройки.
Архитектура — модуль внутри Laravel. Vue отображает страницы через Inertia.
Связи объектов:
User — аккаунт тренера
├── TelegramIdentity — привязанный Telegram
└── Workspace — единственное рабочее пространство
├── WorkingInterval[] — интервалы недельного графика
├── TrainingService[] — услуги
└── BookingRules — общие правила записи
Обработка изменений:
Vue → PanelController → Service → Repository → PostgreSQL
- WorkspaceService — создание пространства, профиль и фото.
- ScheduleService — график и правила.
- TrainingServiceService — создание, изменение и отключение услуг.
- FormRequest проверяет данные, Policy — принадлежность объектов тренеру.
- Fortify отвечает за email-вход; TelegramTokenVerifier проверяет Telegram-токены.
- После сохранения отправляются доменные события; письма идут через RabbitMQ.
  Тесты есть: прошли 50 тестов на PostgreSQL — 209 проверок. Проверяются авторизация, изоляция тренеров, график, услуги и Telegram-подписи. Дополнительно прошёл браузерный сценарий с письмами, восстановлением доступа и экраном 360 px.
