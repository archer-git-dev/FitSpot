# FitSpot

SaaS для частного персонального тренера. Реализован модуль 1, блок А: панель настройки рабочего пространства.

Стек: Laravel 13 / PHP 8.3, Vue 3 + TypeScript + Inertia, Tailwind CSS 4, PostgreSQL 16, Redis 7, RabbitMQ, Docker Compose.

- [ТЗ блока А](docs/specs/module-1-block-a.md)
- [ExecPlan и результаты](docs/execplans/module-1-block-a.md)
- [Запуск, демо, тесты и Telegram](docs/README-block-a.md)

После установки зависимостей, сборки, настройки .env и обычных миграций панель доступна на http://localhost:8080, почта разработки — http://localhost:8025.

Публичная запись, Telegram-уведомления, Google Calendar и следующие модули пока не реализованы.
